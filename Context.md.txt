# Project Context: DOF-AI v2 (Agentic Legal RAG System on AWS)

## 1. Project Objective
DOF-AI v2 is an agentic legal intelligence platform designed to query, retrieve, and synthesize Mexican legislation and daily publications from the *Diario Oficial de la Federación* (DOF). 
Unlike v1 (a linear LangChain pipeline), v2 implements a stateful, self-correcting agentic architecture that eliminates legal hallucinations by strictly grounding answers in retrieved articles and real-time DOF summaries, citing exact article numbers, laws, and publication dates.

## 2. Core Tech Stack & Constraints
- **Primary Language:** Python 3.11+
- **Agent Framework:** LangGraph (`langchain-aws` with `ChatBedrockConverse` using Claude 3.5 Sonnet/Haiku or Amazon Nova).
- **Tool Protocol:** Model Context Protocol (MCP) via official Python `mcp` SDK (`FastMCP`) for real-time DOF scraping/queries.
- **RAG & Vector Store:** Pinecone (Serverless Free Tier) + Amazon Bedrock Embeddings (`amazon.titan-embed-text-v2:0`).
- **Backend:** Django 5 + Django REST Framework (DRF) with streaming support (SSE).
- **Frontend:** React (Vite + TypeScript + Tailwind CSS).
- **Cloud & Infrastructure (AWS):** Amazon Bedrock, AWS Lambda (ingestion & MCP server), Amazon S3 (raw legal docs & frontend static hosting), Amazon ECR, AWS ECS Fargate (Django backend).
- **IaC & CI/CD:** Terraform + GitHub Actions.
- **Cost Constraint:** Strictly optimize for AWS Free Tier / pay-per-use. Do NOT provision NAT Gateways, OpenSearch Serverless, or always-on EC2 instances. Use default VPC public subnets with strict Security Groups for Fargate tasks to keep costs near $0.
